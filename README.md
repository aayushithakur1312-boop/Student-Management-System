# Student Management System

A simple student management web app built with HTML, CSS, and JavaScript.

## Features

- Add student records
- View students in a responsive table
- Search by student ID, name, or course
- Edit student records
- Delete student records with confirmation
- Validate age, email, phone number, and duplicate IDs
- Persist data in the browser using `localStorage`

## Run locally

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` directly in a browser, or use VS Code's Live Server extension.
3. Add and manage student records.

The records are saved in the browser's local storage for this site.
